# مدرّبون سعوديّون | Saudi Trainers

منصة تفاعلية بديلة لموقع Google Sites الحالي ([sauditrainers.sa](https://www.sauditrainers.sa/)): دليل ذكي للمدربين السعوديين، وبطاقات تعريفية احترافية قابلة للمشاركة، ونموذج تسجيل بخطوات مع مسار قبول كامل، ولوحة خاصة لكل مدرب، ولوحة إدارة بالدخول عبر حساب Google.

الموقع ملفات ثابتة (HTML / CSS / JS) لا تحتاج أي بناء، والبيانات في Firebase Realtime Database (أو في المتصفح للتجربة).

## الصفحات

| المسار | الوصف |
|---|---|
| `#/` | الواجهة الرئيسية: خريطة نقطية تفاعلية للمملكة بعدد المدربين في كل منطقة، بحث فوري مع اقتراحات، نخبة المدربين، التخصصات، المناطق، الانضمام، الأسئلة الشائعة |
| `#/trainers` | دليل المدربين: بحث عربي ذكي (يتجاهل الهمزات والتشكيل) + فلاتر المنطقة والتخصص وطريقة التقديم والجنس، والرابط يحفظ الفلاتر |
| `#/t/{رابط}` | صفحة المدرب: بطاقة ثلاثية الأبعاد بلمعة هولوغرافية، مشاركة، حفظ صورة منشور 4:5 وقصة 9:16 مع QR، طلب المدرب مباشرة |
| `#/join` | التسجيل كمدرب: 5 خطوات، معاينة حيّة للبطاقة، رفع الصورة وقصّها تلقائياً، حفظ المسودة تلقائياً، رقم طلب للمتابعة |
| `#/status` | متابعة حالة الطلب بخط زمني وملاحظة من الإدارة |
| `#/request` | اطلب مدرباً: ترشيحات فورية بنسبة توافق (التخصص + المنطقة + الموضوع + طريقة التقديم)، ويصل الطلب للإدارة |
| `#/halls` | قاعات التدريب: عرض القاعات، وطلب قاعة أو عرض قاعة |
| `#/about` | عن المنصة |
| `#/login` → `#/me` | لوحة المدرب: المشاهدات والنقرات والطلبات، تعديل البطاقة بمعاينة حيّة واختيار تصميمها (6 ثيمات)، صور جاهزة للمشاركة، الطلبات الواردة |
| `#/admin` | لوحة الإدارة (بحساب Google) |

**روابط الموقع القديم** (`/about`، `/register`، `/Find-major`، `/book`، `/ابحث-عن-مدرب-بالمناطق/Riyadh` ...) تتحول تلقائياً إلى الصفحات الجديدة عبر `404.html`، فلا تتعطل الروابط المنشورة سابقاً.

## لوحة الإدارة

- **المؤشرات:** المدربون المنشورون، الطلبات، المشاهدات والنقرات، التوزيع حسب المنطقة والتخصص، الأكثر مشاهدة، تنبيه بمن تنتهي مدة نشرهم.
- **طلبات التسجيل:** لوحة كانبان بالسحب والإفلات (جديد ← مراجعة ← استيضاح ← مقبول بانتظار السداد ← نشر / رفض). من تفاصيل الطلب: ملاحظة تظهر للمتقدم، رسالة القبول وبيانات السداد عبر واتساب أو البريد، و**نشر البطاقة وإصدار رمز الدخول** بضغطة.
- **المدربون:** تعديل كامل، تمييز، إخفاء، تمديد النشر سنة، إصدار/تجديد رمز الدخول مع رسالة جاهزة للإرسال، استيراد CSV/JSON، تصدير CSV.
- **طلبات الجهات، القاعات، المحتوى** (نصوص الواجهة والرسوم والمتطلبات والسداد والأسئلة)، **المشرفون** (دعوة بحساب Google)، **البيانات والسجل** (نسخ احتياطي، استرجاع، سجل النشاط، بيانات تجريبية).

## الإعدادات — `js/config.js`

| المفتاح | الوصف |
|---|---|
| `firebase` | إعدادات تطبيق الويب من Firebase. `null` = الوضع المحلي للتجربة (البيانات في المتصفح فقط، ودخول الإدارة تجريبي). |
| `dbRoot` | المسار الجذري للبيانات (`sauditrainers`). |
| `ownerEmails` | الحسابات الرئيسية للإدارة (يجب أن تطابق `OWNERS` في `tools/build_rules.py`). |
| `adminIdleHours` | مدة بقاء المشرف مسجلاً دون نشاط. |
| `siteUrl` | رابط المنصة. |

## التفعيل (الوضع الآمن)

1. أنشئ مشروعاً في [Firebase Console](https://console.firebase.google.com/) وفعّل **Realtime Database**.
2. Authentication ← Sign-in method: فعّل **Google** (للإدارة) و**Email/Password** (تستخدمه رموز دخول المدربين داخلياً).
3. Authentication ← Settings ← Authorized domains: أضف نطاق الموقع (مثل `www.sauditrainers.sa` و`hussain-al-hajji.github.io`).
4. أضف تطبيق ويب وانسخ إعداداته إلى `firebase` في `js/config.js`.
5. انشر القواعد: انسخ محتوى `database.rules.json` إلى Realtime Database ← Rules ← Publish. (عند تعديلها: `python3 tools/build_rules.py`.)
6. افتح `#/admin` وادخل بأحد الحسابات الرئيسية عبر Google.

**الأدوار في القواعد:**
- **الزائر:** يقرأ المحتوى العام فقط، وينشئ الطلبات (تسجيل، اطلب مدرباً، طلب مدرب، قاعات) دون قراءة ما أرسله غيره. كل حقل مُتحقَّق من نوعه وطوله، والحقول غير المعروفة مرفوضة.
- **المدرب:** يعدّل الحقول العامة لبطاقته وصورته فقط (لا يستطيع تغيير الحالة أو التمييز أو مدة النشر)، ويقرأ بياناته الإدارية والطلبات الموجهة له.
- **الإدارة:** الحسابات الرئيسية (بريد Google مُتحقَّق) ومن دعتهم؛ تُفعَّل الدعوة تلقائياً عند أول دخول بحساب Google المدعو.
- رمز دخول المدرب بصيغة `ST0012-7K4Q9P` (رقم المدرب + لاحقة سرية عشوائية)، ويُجدَّد من لوحة الإدارة.

## نقل البيانات من الموقع الحالي

1. صدّر بيانات المدربين من Google Sheets المرتبط بالموقع الحالي: ملف ← تنزيل ← CSV.
2. الإدارة ← المدربون ← **استيراد**: تُطابق الأعمدة تلقائياً (الاسم، اللقب، المنطقة، المدينة، الجوال، البريد، واتساب، التخصصات، البرامج، النبذة، سنوات الخبرة، رابط الصورة...)، وتُطابق أسماء المناطق والتخصصات مع التصنيف الجديد، وتظهر معاينة قبل الاعتماد.
3. أصدر رموز الدخول من فلتر «بلا رمز دخول» وأرسلها للمدربين برسالة جاهزة.
4. احذف البيانات التجريبية (إن أضفتها) من «البيانات والسجل».

## النشر

- **GitHub Pages:** الإعدادات ← Pages ← الفرع والمجلد `/ (root)`.
- **النطاق sauditrainers.sa:** أضف ملف `CNAME` بالنطاق، ووجّه سجلات DNS إلى GitHub Pages بدلاً من Google Sites.
- **محلياً:** `python3 -m http.server` ثم `http://localhost:8000`.

## الهوية البصرية

- الألوان: زمردي داكن (`--g800 #0A3D2A`) وذهبي (`--gold #C9A24A`) ورملي فاتح، مع نقش النجمة الثمانية النجدية.
- البطاقات: صورة المدرب داخل **قوس نجدي**، إطار ذهبي، شارة توثيق، مؤشرات الخبرة، وستة ثيمات يختار منها المدرب.
- الخطوط: **Cairo** للعناوين والأرقام البارزة، **IBM Plex Sans Arabic** للواجهة، **Noto Sans Arabic** للنص. الأرقام إنجليزية دائماً.
